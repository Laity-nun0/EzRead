# EzRead

[简体中文](README.md) · [Download](https://github.com/Laity-nun0/EzRead/releases/latest) · [Feedback](https://github.com/Laity-nun0/EzRead/issues/new/choose)

**A Windows desktop reader for researchers and students who organize local papers and read English PDFs alongside Chinese translations.** The current application UI is in Chinese.

This independently maintained derivative of [zhuangcao136-glitch/EzRead](https://github.com/zhuangcao136-glitch/EzRead) preserves the upstream MIT notice and history. The features below describe released **3.5.6**, checked on 2026-10-21. See [provenance](docs/DERIVATION.md) and [maintenance evidence](docs/MAINTENANCE.md) for implementation, release and verification links.

## What works today

- Import PDFs, search and filter a local library, manage favorites and manual collections.
- Read several papers in tabs; restore tabs, reading positions and notes after restarting.
- Generate derived Chinese and bilingual PDFs through BabelDOC and your own DeepSeek API access; compare original and translated PDFs with synchronized scrolling.
- Ask questions about the current paper using a separately configured API key; keep conversations and notes locally.
- Back up the library, migrate its directory through Settings, and upgrade or uninstall while retaining user data.

## Install and try

Use Windows 10 1809 or later, x64, with .NET Framework 4.8 and WebView2. Download `EzRead-<version>-Setup-x64.exe` from [Releases](https://github.com/Laity-nun0/EzRead/releases/latest). Python and the PDF runtime are included; missing WebView2 requires an internet download during installation. The installer is not commercially code-signed. Other operating systems have not been validated for this desktop edition.

1. Open EzRead from the desktop or Start menu. An empty library is normal on first launch.
2. Choose **导入 PDF** (Import PDF), or drag in a text-based PDF you may use. Click its card to read; **论文简介** opens its details. **文献库** returns to the library so you can open another tab.
3. Open **笔记** (Notes), write a note, move to another page, then close and reopen EzRead to check restoration. This local workflow needs no account, API key or network.
4. Optionally save a DeepSeek key under **设置 → 翻译** (Settings → Translation). Choose **保留版式翻译**, review the task and confirm. Q&A has its own key under **设置 → 问答**. AI requires network access, model permission and available provider quota. Saving a key does not test connectivity.
5. Compare the resulting PDFs and check formulas, figures and meaning. Report what you actually tried using the [trial feedback template](https://github.com/Laity-nun0/EzRead/issues/new?template=trial_feedback.md), or file a [bug report](https://github.com/Laity-nun0/EzRead/issues/new?template=bug_report.md).

No Codex installation or sign-in is needed. The current UI exposes DeepSeek; retained backend protocol compatibility does not make other providers selectable. **Once a translation key is configured, importing a new PDF automatically sends first-page and candidate-heading text for structure checking.** Full translation, Q&A and research overviews follow explicit UI actions. See [data sent to APIs](docs/AI_API.md#使用与发送范围).

## Limits, data and contribution

Complex layouts, scanned PDFs, unusual fonts, formulas and rotated text need manual review. A successful job or simulated test does not establish translation accuracy or complete visual fidelity. PDF coordinate annotations and manual translation editing are not exposed in the current reader. See [PDF limitations](docs/PDF_LAYOUT.md) and [known issues and fixes](docs/KNOWN_ISSUES.md).

Installed data defaults to `%LOCALAPPDATA%\EzRead\data`; source runs use the repository's `data/`. Export a backup and close EzRead before upgrading. Exported backups exclude API keys. See [installation and migration](docs/INSTALLER.md).

For source setup and checks, use [CONTRIBUTING.md](CONTRIBUTING.md); detailed technical guides are currently in Chinese. Submit issues in Chinese or English with the app version, OS version, reproduction steps, expected and actual results. Remove keys, authorization links, private papers and personal details from attachments; do not upload a whole library or raw API responses.
