# 二次开发与独立维护

本仓库由 Laity-nun0 在 [zhuangcao136-glitch/EzRead](https://github.com/zhuangcao136-glitch/EzRead) 的基础上深度二次开发，继续使用 EzRead 名称。目前的翻译主路径、阅读界面和 Windows 发布由本仓库独立维护，不是原作者的官方发行版，也不是完全从零编写的软件。

## 来源与版本边界

本轮改造基于上游提交 `f0b98b09812b4a0c3410bf6b6118c85aa682dcd1`。保留此前公开提交历史及根目录 MIT 版权声明。原作者仓库在本地以 `upstream` 作为只读参考；本仓库的提交和安装包发布在 `Laity-nun0/EzRead`，不会自动写入上游。

本仓库的 `3.5.x` 版本按当前界面和本地改造发布，没有合入上游之后另行开发的 PDF 手动校订及对话扩展，不能通过比较版本号判断两者功能包含关系。

## 主要改造

- 全文翻译从依赖 Codex CLI 的文本块流程迁至共享 API 传输和 BabelDOC 原生版式处理，生成派生单语、双语 PDF。
- 为每篇任务冻结源文件、模型、协议和术语，保留响应缓存、暂停恢复及旧版本；检查响应完整性、文字／公式对象、PDF 文件与页面结构后提交。核验不能替代人工判断语义质量。
- 阅读界面改为 PDF 主导，保留同步滚动、阅读位置、笔记与论文问答。旧 HTML 全文翻译和正文编辑入口已经退役。
- 重做文献库、最近阅读、主题切换、书本与 AI 图标及原生标题栏；提供独立 Windows 安装包与安全目录迁移。

当前用户入口开放 DeepSeek。底层其他供应商协议、旧字段与迁移逻辑仍有兼容用途，不代表这些旧功能均在当前界面可用。实现边界见 [API 说明](AI_API.md) 和 [PDF 翻译说明](PDF_LAYOUT.md)。

## 遗留内容处理原则

旧界面宣传、历史截图与过时安装说明已替换。当前展示图由 `scripts/capture-showcase.py` 在独立库中生成，所有文献、配图与中文演示 PDF 均为合成内容，没有使用用户的文献库或模型账号。

图标源图合并到实际使用的 `static/ezread-icon.png`，删除内容完全相同的重复副本；重建脚本集中到 `scripts/build-windows-icon.py`。

旧 Codex PDF 通道专用诊断脚本已经退休；普通验证使用当前 API 和 PDF 流程。仍被使用的测试、旧文献字段、历史译文、批注、草稿及恢复接口继续保留，不能因文件名旧或来自原作者就删除。源码历史由 Git 保存。
