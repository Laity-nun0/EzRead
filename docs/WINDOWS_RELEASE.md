Windows 10/11 x64 安装版。由 Laity-nun0 基于 [原项目 EzRead](https://github.com/zhuangcao136-glitch/EzRead) 深度二次开发、独立维护，保留原项目版权声明、许可和提交历史。当前版本不是原作者的官方发行版。

3.5.6 更新：

- 支持删除合集，确认后移除合集及其归属，保留其中的论文、原 PDF、译文、笔记和阅读状态。
- 修复 PDF 页面逐步绘制和重绘清空引起的局部闪动：页面绘制完成后一次显示，重绘期间保留原画面，继续支持文字选择与复制。
- 翻译成功提交后自动清理已知的排版临时 PDF 和旋转处理输入副本。原文、最终单语／双语译文、模型响应缓存、翻译跟踪及核对报告继续保留；失败、暂停和未提交任务保留恢复材料。
- 清理前核对原文和最终译文的哈希，保护最终输出和路径边界；清理遇到文件占用不会把已完成的翻译改成失败。

下载安装文件 `EzRead-3.5.6-Setup-x64.exe`。自带 Python、PDF 阅读与 BabelDOC 全文翻译组件；缺少 WebView2 的电脑首次安装需要联网。AI 功能需配置自己的 API Key，本地阅读无需密钥。安装程序未进行商业代码签名。

安装版数据默认保存在 `%LOCALAPPDATA%\EzRead\data`；升级和卸载保留文献、笔记与设置，不迁移或清理源码目录的原库。已发布版本不会在打开论文时批量清理历史任务目录。

保留已有多文献标签、关闭重开恢复阅读会话、翻译任务退出提醒和文献目录迁移。本版本未整合上游另外开发的 PDF 校订和对话扩展。

`SHA256SUMS.txt` 为下载校验清单，`release-manifest.json` 为安装内容清单。安装目录提供第三方许可和 BabelDOC/PyMuPDF/MuPDF 对应源码；`EzRead-3.5.6-source.zip` 包含本版本源码与重建脚本。普通验证使用合成文献和模拟响应，不证明真实译文的语义或排版质量。
