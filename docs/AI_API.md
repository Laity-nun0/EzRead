# 共享 AI API

当前只开放 DeepSeek。设置中的“翻译”和“问答”分别保存 API Key 与思考设置；官方地址 `https://api.deepseek.com`、单次最大输出 384K（393216 tokens）已预填。翻译固定 `deepseek-flash`，默认关闭思考；问答可选 Flash（`deepseek-flash`）或 Pro（`deepseek-v4-pro`），默认 Flash，默认开启思考并使用 high；开启后可选 low/high/max。保存配置只写本机，不测试连接，不读取远程模型目录，不需要 Codex CLI。旧供应商配置和协议仅保留恢复兼容，不作为当前模型选择入口。

## 使用与发送范围

| 功能 | 何时调用 | 发送内容与一致性 |
| --- | --- | --- |
| 全文翻译 | 在确认窗口提交任务后 | BabelDOC 原始提示词、当前批次与相关本篇术语；连接复用，不累积全部历史；排版仍在本地 |
| 论文问答 | 明确发送问题后 | 当前问题、本轮检索的原文和已存译文、有界笔记与速览，以及最近对话；要求并校验源块引用 |
| 研究速览 | 点击生成速览后 | 当前可读原文，排除参考文献和表格图片块；保留原有内容规则和 JSON 校验 |
| 导入结构校对 | 新 PDF 导入后自动执行一次，或手动重试 | 首页与疑似标题候选、相邻文字及项目自带分类规则；返回源块 ID 与角色，不改写原文 |
| 选句翻译与段落重译兼容接口 | 明确提交经过范围校验的请求后 | 当前文字与本篇相关术语；不发送对话历史；重译前后复查原文和译文版本 |
| 期刊名单修改预览接口 | 明确提交修改要求后 | 当前名单与修改要求；只生成经校验的预览，仍须显式应用 |

当前 PDF 阅读器没有旧正文选区菜单；上述兼容接口不意味着新增了 PDF 选区编辑入口。离线查词保持本地词典查询，未命中不调用 API。旧选句准备接口只检查本机 API 配置，不发送预热请求。

未保存密钥也能导入和本地阅读；结构校对显示待核对并保留规则初稿。模型失败不自动回退到 Codex、不自动更换供应商、不无限重试。只有明确发起上述功能或恢复任务才发送相应论文内容；打开已有文献不批量触发调用。

## 对话、模型与数据

每篇论文只有一个连续对话，合并显示该篇历史消息。问答每轮读取“问答”的配置与密钥，侧边栏可选择 Flash / Pro 和思考强度；本篇显式调整从下一轮生效，不清空消息、不新建版本，也不影响其他论文或全文翻译。未手动覆盖的论文跟随问答设置。旧线程及分代数据继续保存，旧按代际读取接口兼容，界面不再提供版本或外部 Codex 打开入口。

本地完整对话一直保留。每次请求从本篇全部已保存消息取最近至多 14 条、合计 16000 字符的提问、回答或速览，不重复拼入旧交接记录，也不发送 reasoning 历史。超出窗口的早期内容不会自动传入模型，需要时在新问题中明确补充。当前问答提供进度状态，待完整响应通过格式与引用校验后显示答案，暂不逐字流式输出。384K 是输出上限，不是已发送上下文长度或每轮实际用量。

速览入队固定模型配置与对话版本，运行期间改默认值或切换论文模型不会混用。返回无效、被截断、取消，或生成期间原文／速览被修改时，不覆盖原有内容。结构任务也保存公开配置快照，并在提交前验证源指纹、候选覆盖与公式角色；不会改变合集、原文块、译文或笔记。

问答、速览、结构校对、选句、段落重译和期刊预览按功能各复用一个串行 HTTP 连接，连接本身不携带模型记忆，也不自动加载全局 AGENTS、技能目录或代理说明。更换配置／密钥后关闭旧连接；退出应用取消在途和等待请求。全文翻译继续使用独立的每篇连接与缓存。

新建全文任务读取“翻译”配置，默认显式关闭思考（`thinking.type=disabled`），并冻结到任务。设置或确认窗口可开启思考；这不改变问答配置。旧 DeepSeek 任务缺少思考字段时保持原样，避免混用缓存；其他供应商的旧译文与草稿可读，不能继续生成。思考选项变化必须新建任务，不能自动改写已开始的任务。研究速览、导入结构校对和旧选区等兼容功能沿用翻译配置，已排队任务保留原快照。

全文翻译确认窗口可开启 DeepSeek 思考，首次开启选择高，并可选低／高／最高（`reasoning_effort=low/high/max`）。关闭时不发送强度；其他供应商不接收这些 DeepSeek 参数。继续任务显示只读原快照，缺省状态显示“沿用原任务配置”；修改思考或模型须生成新版本，旧 PDF、草稿和缓存保留。分组使用 BabelDOC 原生流程，历史分批实验任务须重新翻译。参数依据 [DeepSeek 思考模式官方说明](https://api-docs.deepseek.com/guides/thinking_mode/)，不把开启思考等同于质量保证。

确认窗口将本篇术语和高级设置折叠，标题与底部操作固定、内容独立滚动；版本与草稿通过独立入口管理。任务卡片只依据实际阶段显示状态，不用文字单元计数推算百分比；“已交付排版”不表示最终 PDF 已提交。失败或暂停停止活动提示，继续入口仍打开确认窗口。纸白主题使用灰白蓝；保留其他主题、期刊等级和批注颜色语义。

无需数据库表迁移。密钥不写入 SQLite、配置快照、交接文件或导出备份；恢复到其他电脑后需重新填写。原 PDF、既有译文、批注、阅读位置、历史对话和草稿保留。旧 Codex PDF 草稿可本地恢复查看状态，不能再通过 CLI 继续；确认窗口要求使用 API 重新生成，归档旧草稿与缓存，不能混合续译。

## 失败诊断与响应留存

传输、HTTP 认证／限流、外层 JSON、异常结束、拒绝／空内容、模型内容 JSON、包装结构，以及内层批次 JSON／ID／占位符分别报告稳定错误码。界面显示短原因，技术详情提供实际取得的 HTTP 状态、响应字节、声明长度、正文是否完整、解析阶段／位置、已报告用量及本机请求标识；缺项显示未知。内层校验仍严格，不猜补截断数据、不放宽 ID 或占位符规则。

全文失败响应保存在实际任务目录 `pdf-layout/<任务ID>/api-diagnostics/<本机请求ID>.json`，独立于成功缓存。仅记录实际收到的字节，以 Base64 保存脱敏后的字节、受控截断状态和安全元数据，不保存请求头、请求正文或底层异常文本。每次诊断最多保留 2 MiB 响应字节，超出部分明确标记；取消／超时可以只有部分字节或没有响应，不能作为完整响应恢复。当前请求密钥及常见凭据字段会脱敏；文件仍可能包含论文或译文，因此仅作本机私有证据，不进入日志、媒体接口、文献导出或 Git。原子新增文件，不覆盖付费响应。

诊断写盘失败保留原错误码，并在详情明确显示保存失败，不宣称证据已保存。有效外层返回但内层校验失败时，原有 `native-replies` 仍先保存付费响应，详情以 `cache-<标识>` 关联。失败诊断不自动回填成功缓存，不自动恢复付费任务或改变供应商；旧错误中已经丢失的响应也不能补造。

诊断脱敏同时识别当前密钥的普通、JSON 转义与 Unicode 转义回显，包括不完整响应中的完整字符串 token 和截断前缀；无关非法 UTF-8 字节保留，不修补或补全响应。HTTP 外层与模型 JSON 内容均不能以重复字段或 NaN/Infinity 通过核验；HTTP 外层错误直接停止，v3 模型批次内容错误交上游标准单段恢复，不重发整个失败批次。

原生 PDF 通道遵循 BabelDOC 的输出契约：批次返回 `id/output` 数组，单段返回纯译文，不强制供应商 JSON 对象模式。新任务使用 `babeldoc-native-v3`：系统提示只保留数据边界，人工术语通过 BabelDOC 原生 `Glossary` 进入其提示词；HTTP 完整成功后的模型文字原样保存、返回，由上游解析或单段恢复。旧任务缺协议字段时沿用 v2 的系统提示、外层术语和包装读取兼容；组件更新不改变其请求契约，明确重新翻译才创建 v3。协议参与缓存身份，新旧缓存不混用。通用问答／选句接口保持原有结构。

v3 的批次格式、ID 或占位符问题交给标准 BabelDOC 单段恢复，清理 JSON 围栏也复用其原方法；重复字段、NaN/Infinity 及错误 ID 仍不能直接通过解析。恢复后正文、公式对象不完整仍不提交 PDF。HTTP／供应商包络损坏、拒绝和传输失败直接停止，不作为可恢复模型内容。标准恢复可能产生额外请求，实际次数写入任务与缓存报告，不承诺每篇只有批次请求。

## 配置状态与用量

登录及订阅额度面板已替换为 API 配置状态和“本次运行 API 用量”。配置已就绪只代表本机参数及密钥齐全，不表示在线验证成功。状态刷新、模型列表和旧 `/api/status`、`/api/usage`、`/api/models` 兼容路由只读取本地信息，不启动 CLI，也不查询供应商账户。

用量从实际 HTTP 发送边界统计，按供应商与模型分组，应用重启后清零；缓存命中和本机准备不计入请求。成功表示收到完整、有效的协议 JSON，不等于论文引用或译文质量通过业务校验。只累计供应商已报告的 token，缺失项显示未知，同时显示报告覆盖的请求数；供应商各字段口径可能不同，不自行补算总量。余额、价格及最终费用以供应商控制台为准。

每个模型单独显示供应商报告的思考 token，不重复加到合计。DeepSeek 的输出统计包含推理明细，因此输出量可能远大于可见译文。任务的 `model_calls` 是本次执行的新请求数，`reused` 是复用的文字单元数；跨暂停恢复保留的缓存和其中历史用量不代表本次再次计费，不能直接与账户时间范围内的请求数对账。

## 离线验证

`scripts/check.py` 覆盖协议解析、连接复用／取消、配置冻结、历史保留、引用／结构校验和任务失败边界。`tests/test_shared_api_http.py` 与 `tests/test_api_only_http.py` 使用隔离文献库及回环模拟供应商贯通真实 HTTP 路由，禁止 Codex 调用。`scripts/verify-api-translation.py` 验证设置保存、宽窄矮窗口、用量展示、旧草稿转 API、聊天版本迁移和模型切换；模型响应明确模拟。

这些检查不调用真实模型，不证明供应商账号可用、实际输出质量或费用。真实模型效果须在用户另行授权后验证。

`scripts/verify-api-translation.py --native --executable work/desktop-build/EzRead.Desktop.exe` 使用独立库、profile、verification session 和宿主 smoke 的实际窗口几何，检查翻译确认框固定头尾、内滚动和思考控件，并核验任务栏隔离日志及窗口退出。实际覆盖的视口保存在 `native-result.json`；不能把宿主的尺寸标签或浏览器结果当作未经测量的原生矮窗口证据。原生测试不提交翻译、不调用真实模型。
